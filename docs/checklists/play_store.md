# Checklist Play Store (générale)

- Nom de l’app, description courte/longue
- Captures d’écran (téléphone) + feature graphic si nécessaire
- Politique de confidentialité (URL) si collecte de données
- Catégorie, email de support, site web (si disponible)
- Classification du contenu (questionnaire)
- Déclaration Data safety (collecte/partage/chiffrement/suppression)
- Signature release (keystore) + sauvegarde sécurisée du keystore
- `applicationId` final (ne plus changer après publication)
