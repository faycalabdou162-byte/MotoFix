# Checklist QA (générale)

## Smoke tests (parcours)

- Lancement app (cold start)
- Onboarding / login / logout
- Dashboard : chargement, actions rapides
- Historique : tri/filtre/pagination
- Profil : modification, sauvegarde, erreurs
- Paramètres : notifications, confidentialité, suppression compte (si prévu)

## Réseau

- Mode avion / réseau lent : états loading/empty/error
- Retry sur erreurs transitoires

## Appareils

- Petits écrans + grands écrans
- Android versions ciblées
